# 📰 News Hive

**News Hive** is a modern, AI-powered news aggregator that curates articles from various sources and delivers them in a personalized, social-media-like feed. Built with the MERN stack, it features dynamic news categorization, search functionality, trending analysis, and user interactions like likes, comments, and shares. The system learns from user behavior to serve smarter recommendations over time.

---

## 🚀 Features

- 🔍 Real-time search and filtering by sources or keyword
- 🧠 AI/ML-powered personalized article feed (Using DBSCAN Clustering)
- 📈 Trending page showing the most engaged-with stories
- ❤️ Like, comment, and share functionality
- 👥 User authentication with email verification and password reset
- 🧵 Admin dashboard for content and user management
- 🕵️‍♂️ Web scraping integration for full article view (free sites only)
- 📱 Mobile-friendly UI with clean, responsive design

---

## 🛠️ Tech Stack

- **Frontend**: React, TailwindCSS
- **Backend**: Node.js, Express
- **Database**: MongoDB (For user interactions and predictions), MySQL (for sessions and admin)
- **Authentication**: SQL Sessions, Nodemailer
- **News API**: [NewsAPI.org](https://newsapi.org/)
- **Machine Learning**: Python (for feed ranking and user behavior modeling)
- **Scraping**: BeautifulSoup, Requests (for full-article fetch)
